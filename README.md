# 水豚温泉 · 3D 造景贴纸

纸盒小景的第三个版本，只做"好看"，没有玩法。灵感来自实体的 3D 造景贴纸套装：一张印好的等距房间场景卡，上面贴满 PET 贴纸。双击 `index.html` 就能看。

- **进场动画**：打开页面后，32 张贴纸从后往前一张张"啪"地贴上去。
- **环境动画**：温泉热气、水面反光、窗外飘雪、灯笼呼吸光、窗户斜照进来的冷光；泡汤的水豚和柚子在水里轻轻浮动；每张贴纸隔一会儿会扫过一道 PET 反光。
- **重来**：右下角「重新贴一遍」可以重放进场动画。

## 美术

场景卡和全部贴纸都由 Codex 的图像生成画，一共 6 张原图，每张都附了提示词。白色模切边、投影和反光是代码加的。生成和处理流程见 `docs/ART_PROMPTS.md`。

## 文件

| 文件 | 内容 |
|---|---|
| `index.html` | 页面、样式、全部 CSS 动画 |
| `js/scene.js` | 贴纸摆放 `LAYOUT`、进场顺序、热气 / 水光 / 雪 |
| `assets/backdrop.jpg` | 场景卡 |
| `assets/stickers.js` | 贴纸（webp data URI），由 `tools/make_stickers.py bake` 生成 |
| `art/raw/` | Codex 原图和提示词 |
| `art/cut/` | 抠好的原图（不带边） |
| `art/layout.json` | 每种贴纸的尺寸 |
