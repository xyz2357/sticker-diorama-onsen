# 水豚温泉 · 3D 造景贴纸

纸盒小景的第三个版本（前两版：[纸盒小景](https://xyz2357.github.io/sticker-diorama/)、[像素小岛](https://xyz2357.github.io/sticker-diorama-pixel/)）。灵感来自实体的 3D 造景贴纸套装：一张印好的等距房间场景卡，加几页 PET 贴纸，自己动手贴。没有反应、委托、打分这些玩法，贴成什么样都行。在线玩：https://xyz2357.github.io/sticker-diorama-onsen/ ，本地双击 `index.html` 也行。

- **自己贴**：
  - 从右边的贴纸页（4 页，32 张）把贴纸撕下来，拖到场景卡上任意位置；
  - 贴歪了可以揭起来再挪，拖回贴纸页就放回原处；
  - 贴纸页上被撕走的位置会留下模切孔。
- **层级**：池塘和木踏板永远垫在最下面，其余贴纸按底边前后自动排。
- **看成品**：弹出成品参考图，里面的「照这个一键贴好」会按参考图一次贴好。
- **全部撕掉重来**：把贴好的贴纸全部放回贴纸页。
- **氛围**：温泉热气和水面反光跟着池塘走；窗外飘雪、灯笼呼吸光；泡汤的水豚贴进池子里会轻轻浮动；贴纸隔一会儿会扫过一道 PET 反光。
- **存档**：贴到哪儿自动存在浏览器里。

## 美术

场景卡和全部贴纸都由 Codex 的图像生成画，一共 6 张原图，每张都附了提示词。白色模切边、投影和反光是代码加的。生成和处理流程见 `docs/ART_PROMPTS.md`。

## 文件

| 文件 | 内容 |
|---|---|
| `index.html` | 页面、样式、全部 CSS 动画、窗外的雪 |
| `js/diy.js` | 贴纸页、拖拽、层级、成品参考 `LAYOUT`、热气 / 水光、存档 |
| `js/audio.js` | 撕、贴的音效（和第一版相同） |
| `assets/backdrop.jpg` | 场景卡 |
| `assets/stickers.js` | 贴纸（webp data URI），由 `tools/make_stickers.py bake` 生成 |
| `art/raw/` | Codex 原图和提示词 |
| `art/cut/` | 抠好的原图（不带边） |
| `art/layout.json` | 每种贴纸的尺寸 |
| `tools/diytest.py` | 无头浏览器里的拖拽测试 |
